# 💳 Finance Bank Simulator

**Finance Bank Simulator** est une application Web réalisée en **HTML / CSS / JavaScript** qui permet de simuler les principaux calculs du cours de **Finance Bancaire** :  
✅ Intérêts simples sur compte d’épargne  
✅ Découvert bancaire (ticket d’agios)  
✅ Escompte (agios + taux réel)  
✅ Annuités (valeur actuelle / valeur acquise)  
✅ Export PDF du bilan (Compte Épargne)

---

## 📌 Objectifs du projet

Ce projet a été conçu dans le cadre du cours de **Finance Bancaire** afin de mettre en pratique les notions suivantes :

- **Intérêts simples**
- **Gestion d’un compte d’épargne**
- **Agios et commissions sur découvert**
- **Escompte bancaire**
- **Annuités / Emprunts**
- **Automatisation des calculs financiers**
- **Génération d’un bilan et export en PDF**

---

## 🖥️ Technologies utilisées

- ✅ **HTML5**
- ✅ **CSS3**
- ✅ **JavaScript**
- ✅ **jsPDF + jsPDF AutoTable** *(export PDF)*
